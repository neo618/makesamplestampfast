# 印章制作工具 - 使用说明

## 📦 复制到新电脑后，如何使用？

### 方法一：最简单（推荐）
**双击 `直接运行-无需环境.bat`**
- ✅ 无需安装任何软件
- ✅ 自动检测并利用系统自带功能
- ✅ 支持 Python 或 PowerShell 自动启动服务器
- ✅ 兼容所有 Windows 电脑

### 方法二：有 Node.js 环境
**双击 `一键启动.bat`**
- 需要预先安装 Node.js（下载地址见下方）
- 功能完整，适合开发人员

---

## 🚀 快速开始

1. **复制整个文件夹** 到新电脑
2. **双击启动脚本**（推荐 `直接运行-无需环境.bat`）
3. **等待 3-5 秒**，浏览器会自动打开
4. **开始制作印章**！

---

## ❓ 常见问题

### 如果脚本没有自动打开浏览器？
手动访问：`http://localhost:8080/`

### 如何停止服务器？
关闭标题为 "印章制作工具 - 本地服务器" 的窗口

### 没有 Node.js 可以运行吗？
可以！使用 `直接运行-无需环境.bat`，无需任何开发环境

### 想安装 Node.js？
- 下载地址：https://nodejs.org/zh-cn/download/
- 推荐安装 LTS 版本（长期支持版）
- 安装后重启电脑即可使用

---

## 📋 文件说明

| 文件 | 用途 |
|------|------|
| `直接运行-无需环境.bat` | 通用启动脚本，无需安装任何环境 |
| `一键启动.bat` | 需要 Node.js 环境 |
| `dist/` | 已构建的生产版本 |
| `src/` | 源代码（开发人员使用） |

---

## ⚙️ 系统要求

- Windows 7 及以上
- 任意现代浏览器（Chrome、Edge、Firefox 等）
- 不需要 Node.js 或 Python（使用便携版脚本时）
